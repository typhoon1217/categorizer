# Categorizer Roadmap

## Planned Features

### History panel with preview
- Show recent move operations in a collapsible panel
- Small thumbnail preview for images, icon for other file types
- Display "filename → folder" for each entry
- Scrollable list, newest on top
- Clickable to undo specific moves (stretch goal)

### Per-directory colors
- Let users assign a color to each subdirectory
- Show color indicator in sidebar folder list (dot or highlight)
- Show matching color in history panel entries
- Persist color assignments in `.categorizer-keys.json` alongside keybindings
- Default palette auto-assigned, customizable via keybinding editor
